This folder contains other git repos that we use aka git submodules. These repos often publish artifacts to mavenCentral, but we need to customise them, so we have the source in tree. Using a submodule is better than just copy and pasting the source code because it allows us to keep track of our patches and manage updating when upstream changes more easily. Using a submodule has the downside of cloning the whole repo and not just the files we want, so we keep the submodules in a separate directory and symlink to the folders we want to use.
